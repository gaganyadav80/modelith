## 0.1.0

- Initial release: `ModelGenerator` and the `modelith` builder, producing json
  functions, a `copyWith` extension and the `_$Foo` mixin in a single part file.
- The mixin carries `==`, `hashCode` and `toString`, never `toJson()`; equality is
  emitted field by field with the comparison picked from each field's static
  type at build time.
- Equality covers inherited fields. `ClassShape` walks `extends` and `with`
  superclass-first, which is the same list and order `json_serializable`
  serializes, so `==` and `toJson` cannot disagree about what a model holds.
  Fields reached only through `implements`, and a superclass's private fields
  from another library, stay out — no generated member can read them.
- `@ModelEnum` enums are generated by the same builder, through
  `json_serializable`'s `JsonEnumGenerator`. Class and enum fragments share one
  `Set`, so an enum map is emitted once however many models hold the enum and
  whether or not it also asks for `alwaysCreate`.
